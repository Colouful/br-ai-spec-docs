# 前端组件库/设计系统 工程标准

## 适用技术栈

- **语言**：TypeScript 为**对外 API** 的单一真源；`.d.ts` 与**源码**同步发布或从源码生成。

- **UI 基座**：**框架绑定型**（如 React+Radix/Headless+CSS、Vue SFC+CSS 变量）或**框架无关+适配层**；须明确**最低支持的框架与浏览器**版本，并在 `peerDependencies` 中声明 `react`/`vue` 范围。

- **构建工具**：Vite/rollup/tsup/Storybook+builder 等组合，须产出 **ESM** 为主、**CJS** 是否保留由宿主生态决定，并在文档与 `exports` 字段中写清**入口映射**与**条件导出**（`import` / `require` / `default` / `types`）。

- **样式与主题**：CSS Modules、Vanilla CSS 变量、Tailwind（插件/预设）、**token** 体系（`design-tokens` JSON → 工具链）之一或组合；**禁止**将业务色名（如 `brand-xxx-销售专用`）当作公共 token 名，除非有品牌规范背书。

- **质量与文档**：Storybook、Ladle、Docusaurus 等之一；**可访问性**（a11y）为默认门禁（axe、eslint-plugin-jsx-a11y 等）。

## 适用项目类型

- **可发布 npm 的组件库/设计系统**，供**多个**应用/团队消费。

- **内源（internal registry）** 的共享 UI 包，**版本与发布节奏** 与**兼容策略** 同样适用本标准。

- **多包 Monorepo 中的 `packages/ui`**，与**应用**通过 workspace 或 CI 发版**联动**；**不**与某个具体业务应用仓库强耦合为唯一消费者。

## 目录结构规范

- **包根目录**：`src`（或 `lib`）按**原子/复合/模式**或**primitives/compose** 分层；`stories`/`docs` 与**源码**一一可导航；`tokens` 与**主题**独立目录，避免与某个业务 feature 同目录混放。

- **导出入口**：`package.json#exports` **显式** 列出子路径，避免深路径被外部依赖；`package.json#files` 与 `.npmignore` 避免泄漏**源图**、未构建源码（除非 intentional）。

- **边界**：**无**业务数据获取、**无**项目路由/权限硬编码、**无**对单一后端域模型名的耦合；`peer` 与**可选依赖** 声明清晰，避免在库内安装 `host` 应用才该有的 polyfill/全局 shims。

- **多框架**：`react/`、`vue/` 子包或**单独包名**；共享逻辑在**无 UI** 的 `core` 中复用，UI 在各自的 `adapters` 中实现，避免在一个组件文件里**条件编译**到难以维护。

## 组件规范

- **职责**：**展示与交互**为主，**不**内嵌**具体业务规则**与接口调用；`slot`/children/ render props 用于**扩展**而非在库里写死**列表数据来源**。

- **命名与 API 稳定性**：公开 API 为**语义化**、**可演进**的 props；破坏性变更只通过**大版本**；deprecate 期与 codemod（若可）在 CHANGELOG 体现。

- **状态**：**受控/非受控** 成对设计（如 `value`+`onChange` 与 `defaultValue`）；不隐藏**重要内部状态**导致**不可控**的 UX。

- **样式**：**主题** 通过 className 前缀/ CSS 变量 / token 名注入；不依赖宿主全局类名**碰撞**无防护；`scoped` 或**CSS-in-JS** 的 ssr/水合注意**与**文档。

- **复用边界**：仅沉淀**可重复出现 ≥3 次**或**强品牌/无障碍** 要求的模式；业务列表页**不应**在库里「示例即实现」为真实接口。

- **a11y**：**键盘**、**焦点阱**、**roving tab index** 等在复杂组件中**有文档有测试**；WAI-ARIA 与**无障** 规范优先于**像素**。

## 路由规范

- **无**：组件库**通常不包含**应用级路由；若带 `Modal`+**深度链接** 类需求，在**使用文档**中说明**由宿主** 提供 `history` 或**回调**，库内**不**import `next/router`/`vue-router` 作为硬依赖，除非有**显式** optional peer 的 adapter。

- **深链接/Story**：Storybook 里用**自包含** 路由 mock，**不** 进入消费者仓库的路由表。

- **多页文档站点**：Docusaurus 的**站级路由** 与**组件**解耦，导航由文档工程维护，**不**混进发 npm 的 UI 包入口。

## 状态管理规范

- **无全局业务 store**；**局部** 状态在组件与**可组合** hooks/ composable 中；**跨**组件的仅**可复现** 的**主题/密度/方向** 等，通过 **Context/Provider** 与 **document** 上的**属性/类** 可观测。

- **与宿主状态**：不强制 **Redux/Pinia**；**注入** 仅通过 props、render 或**官方** 推荐的 composition API，无**自造** 全局 `window` 单例**注册表** 除非有**品牌级** 理由并文档与类型齐全。

- **数据**：**不** 内置 fetch；若提供**展示用** `AsyncList` 类复合组件，**泛型**+**可注入** 的 `load` 为唯一扩展点，**不** 写死 URL。

## 接口请求规范

- **默认** 库**无**网络；**不** 暴露 axios 实例、**不** 要求消费者配置 `baseURL` 为库能跑。

- **可扩展**：若**可选** 模块提供**云图标/CDN 字体** 等，在**显式** `peerOptional` 或**文档**中说明，且**不** 在**默认** bundle 中。

- **类型**：公共类型**不** 依赖**后端** OpenAPI 名称；`DataSource` 等**泛名**+**T**。

- **错误/Loading**：若复合组件有 **异步** 子块，**UI 状态**（loading/empty/error） 为**纯展示**，**重试** 为**可逆** 的用户操作，**不** 自动无限重试（除非有明确 a11y/网优理由且可关闭）。

## 表单规范

- 表单元素与 **label**、**error**、**hint** 的**关联** 为**默认**；**与** `react-hook-form` / `@tanstack/react-form` / 第三方 form 的**适配以** 文档+**不破坏** 受控/非受控 为前提。

- **不** 在库内**提交** 到**真实** API；`onSubmit` 由**宿主** 接。

- **i18n**： 文案**可覆盖** 或 通过 props；**不** 内置长业务句子。

- **可访问性**：`aria-invalid`、**聚焦到第一个错误** 的**行为** 若**无法** 跨宿主一致，在文档中**明确** 与**可覆盖** 钩子。

## 权限规范

- **无** 内建**业务** 权限点；`disabled`、**只读**、**隐藏** 由**宿主** 以 props/策略函数注入。

- **不** 在**文档** 中**暗示** 库能**代劳** 访问控制，**不** 提供「伪权限」 组件 除非 通用 **RBAC/ABAC 无关** 的**视觉** 模式（如 skeleton-only）。

- **不** 将**可枚举** 的全量权限列表**打包** 进**公开** 包，除非 经**安全** 评审 且 **用途** 仅为**无敏感** 的 静态文档。

- **可观测**：若提供 **feature flag 外观** 的 UI，**不** 读取 远程 flag，**仅** 接 props。

## 测试规范

- **单测/组件测**：Jest/Vitest + Testing Library 或 框架等效；**快照** 仅 用于**稳定** 的**小** DOM/ token，不**大段** 快照 代替**交互** 断言。

- **a11y 测**：`axe` 在 CI 对**关键** stories/组件 跑，**不** 只人工。

- **视觉回归**：Chromatic/Playwright+截图 的**基线** 有**明文化** 流程；**多主题/RTL** 覆盖 策略。

- **E2E**：不**在** 库里**对** 真实 后端 跑 通； 若**有** 集成**示例应用**（`playground`），E2E **仅** 在 `examples` 中。

- **包体积/Tree-shaking**：`import` **barrel 文件** 不**无差别** 拖入**大** 依赖；**有** 体积预算 与 **#sideEffects** 的**审计** 清单。

- **发布前**：`changeset`/`bumpp` 的**说明** 与**迁移** 指南；**破坏性** 变更 **有** 迁移片段。

## Rule 生成要求

- **生成约束**：**`exports` 契约**、**stories 必须** 带 **a11y 面板**、**token 命名**、**peer 范围**、**不** 引用**单业务** 名词、**文档** 与**类型** 同发布。

- **禁止行为**：禁止 在 Rule 中 要求 组件库 **内嵌** 任何 **具体** 项目 **路由/接口/权限**；禁止 **默认** 安装 **与宿主冲突** 的全局 polyfill。

- **验收标准**：**消费者** 用 **最小** 的 `import` 可 **成功** 类型检查与 运行；**不** 暴露 **未** 在 `exports` 的**内路径** 为 官方 用法（除非 文档化 并 **稳定**）。

## Skill 生成要求

- **输入**：**设计** token/figma、**无障碍** 要求、**目标** 框架/版本、**已** 有 的 同类 组件 对比、**迁移** 路径（从 vN 到 vN+1）。

- **步骤**：`token` 对齐 → 组件 API 设计评审 → 实现+stories+单测+axe → **文档**（用法/限制/键盘） → **尺寸** 与 **a11y** 验收 → 发 **changeset** 或 **内源** 发版 流程。

- **输出**：**CHANGELOG**、**story** 链接、**可复制** 的 用法 代码块（**短**、**不** 含 业务 接口）、**breaking** 迁移 说明。

- **异常处理**：**ssr/水合** 差异、**多版本** 同一页（微前端）**的** 样式/主题 冲突 时 的 故障单 与 规避（**BEM/ CSS 层** 等）记录。

## Flow 生成要求

- **阶段**：**RFC/ADR**（API/主题/破坏性） → 设计 → 实现+测试+文档 → **设计评审+无障碍评审** → **预发** 到 示例 应用/Storybook 预览 → **发版** `semver` 正确。

- **门禁**：**lint+type+test+axe+build** 全绿；**包体积** 不**超** 预算；**peer** 不**冲突**；**license** 与 第三方 声明 完整。

- **状态流转**：`canary`/`beta` → `latest` 的 推广 与 **消费者** 升级 窗口；**内源** 与 **公网** npm 的 同步 或 **延迟** 在 清单 中。

- **异常出口**：`deprecated` 组件 的 文档 **横幅**+**时间线**；**回滚** 的 **yanked** 或 文档 **别用** 声明。

## Manifest 推荐

- **推荐资产组合**：`tsup` 或 `rollup` preset、`tsconfig` 的**双包** 思路（`types` first）、`storybook@latest`+**`@storybook/test`**、**`eslint-plugin-jsx-a11y`** 或 等价、**`changesets`/`semantic-release`（二选一 且 固定）**、**`size-limit`**、**`bundlewatch`**、**Figma/ token** 同步 脚本 占位（不**绑定** 单一 厂商 若无）。

- **安装策略**：**`peer` 先行** 安装 指南；**不** 建议 消费者 **pin** 到 未文档化 的 内链；**子路径** 导出 的 **稳定性** 与 文档 同步 更新。

## 禁止行为

- **不** 输出 可 **直接** 连接 **生产** 的 **业务** 实现（含 **完整** CRUD 页面 代码 作为 库 的一部分）。

- **不** 虚构 **npm 包** 的 **已发布** 版本/下载量；**不** 为 **未存在** 的 `peer` 写 范围，除非 **标注** 计划 与 兼容 假设。

- **不** 跳过 **无障碍** 与 **键盘** 验收；**不** 以 **图** 替代 **可测试** 的 规格。

- **不** 在 **不声明** 副作用 的 情况下 改变 **`<html>`/`<body>` 全局** 的 **不可预期** 行为；若 **Portal** 到 `document.body`，**类名**/**z-index**/**焦点** 须 **有** 规约。

- **不** 将 **Story 中的 mock 数据** 与 **可导入** 的 公共 导出 **混放**，避免 **把 mock** 当 **公 API** 误用。

## 验收标准

- 第三方 **最小编译应用** 可 `import` **仅** 所需 组件 **且** 类型/样式 正确；**Story** 在 **多主题/RTL/键盘** 下 可 演示；**CHANGELOG** 与 **semver** 一致；**`npm pack` 内容** 无 **秘钥/源图泄露**（除非 明确 的 source map 策略）；**peer** 警告 在 文档 中有 解释 与 **可运行** 的 版本 矩阵 表。
