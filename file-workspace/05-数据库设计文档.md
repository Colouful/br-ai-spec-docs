# 数据库设计文档

## 1. 设计目标
数据库设计需支持以下能力：
- Workspace 与项目接入管理
- Run / Change / Spec 等核心运行数据
- 资产扫描结果
- 安装与使用埋点
- 首页聚合查询
- 试点项目与复盘信息

## 2. 核心表设计总览

### 2.1 基础关系类
- workspace
- workspace_member
- project
- project_connection

### 2.2 运行态类
- run
- run_event
- change_record
- spec_record
- block_record
- archive_record

### 2.3 资产类
- asset_scan_record
- asset_item_status

### 2.4 安装与统计类
- installation_record
- installation_event
- dashboard_event_log
- efficiency_snapshot

### 2.5 试点类
- pilot_project
- pilot_review_record

## 3. 表结构建议

### 3.1 表：workspace
| 字段 | 类型 | 说明 |
|---|---|---|
| id | varchar(64) | 主键 |
| name | varchar(255) | 工作区名称 |
| description | text | 描述 |
| mode | varchar(32) | demo / real |
| status | varchar(32) | active / inactive |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

### 3.2 表：workspace_member
| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint | 主键 |
| workspace_id | varchar(64) | 工作区 ID |
| user_id | varchar(64) | 用户 ID |
| role | varchar(32) | admin / maintainer / viewer |
| created_at | datetime | 创建时间 |

### 3.3 表：project
| 字段 | 类型 | 说明 |
|---|---|---|
| id | varchar(64) | 主键 |
| workspace_id | varchar(64) | 工作区 ID |
| name | varchar(255) | 项目名称 |
| repo_url | varchar(512) | 仓库地址 |
| business_type | varchar(64) | 业务类型 |
| status | varchar(32) | connected / running / archived |
| owner | varchar(128) | 负责人 |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

### 3.4 表：run
| 字段 | 类型 | 说明 |
|---|---|---|
| id | varchar(64) | 主键 |
| workspace_id | varchar(64) | 工作区 ID |
| project_id | varchar(64) | 项目 ID |
| change_id | varchar(64) | 关联 change |
| name | varchar(255) | 需求名称 |
| flow_type | varchar(64) | 交付链类型 |
| current_phase | varchar(64) | 当前阶段 |
| current_role | varchar(64) | 当前角色 |
| status | varchar(32) | running / blocked / archived / failed |
| demand_type | varchar(64) | component-replace / bugfix |
| risk_level | varchar(32) | low / medium / high |
| started_at | datetime | 开始时间 |
| updated_at | datetime | 更新时间 |
| archived_at | datetime | 归档时间 |

### 3.5 表：run_event
| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint | 主键 |
| run_id | varchar(64) | Run ID |
| event_type | varchar(64) | started / status_changed / blocked / resumed / archived |
| previous_status | varchar(64) | 上一状态 |
| current_status | varchar(64) | 当前状态 |
| current_phase | varchar(64) | 当前阶段 |
| current_role | varchar(64) | 当前角色 |
| blocked_reason | varchar(255) | 阻塞原因 |
| payload | json | 扩展信息 |
| created_at | datetime | 创建时间 |

### 3.6 表：change_record
| 字段 | 类型 | 说明 |
|---|---|---|
| id | varchar(64) | 主键 |
| workspace_id | varchar(64) | 工作区 ID |
| project_id | varchar(64) | 项目 ID |
| name | varchar(255) | 变更名称 |
| type | varchar(64) | change / patch / full-change |
| status | varchar(32) | active / archived / closed |
| archived | tinyint | 是否归档 |
| updated_at | datetime | 更新时间 |

### 3.7 表：spec_record
| 字段 | 类型 | 说明 |
|---|---|---|
| id | varchar(64) | 主键 |
| workspace_id | varchar(64) | 工作区 ID |
| project_id | varchar(64) | 项目 ID |
| name | varchar(255) | Spec 名称 |
| status | varchar(32) | active / archived |
| archived | tinyint | 是否归档 |
| updated_at | datetime | 更新时间 |

### 3.8 表：asset_scan_record
| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint | 主键 |
| workspace_id | varchar(64) | 工作区 ID |
| project_id | varchar(64) | 项目 ID |
| scan_time | datetime | 扫描时间 |
| coverage_score | int | 覆盖评分 |
| created_at | datetime | 创建时间 |

### 3.9 表：asset_item_status
| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint | 主键 |
| scan_record_id | bigint | 关联扫描记录 |
| asset_type | varchar(64) | rules / skills / openspec / ai_spec / registry / logs |
| status | varchar(32) | detected / missing / invalid |
| repair_hint | varchar(512) | 修复提示 |

### 3.10 表：installation_record
| 字段 | 类型 | 说明 |
|---|---|---|

| workspace_id | varchar(64) | 工作区 ID |
| project_id | varchar(64) | 项目 ID |
| user_id | varchar(64) | 用户 ID |
| install_mode | varchar(32) | demo / team |

| selected_profile | varchar(64) | profile |

| error_code | varchar(64) | 错误码 |
| error_message | varchar(512) | 错误信息 |
| created_at | datetime | 创建时间 |

### 3.11 表：dashboard_event_log
| 字段 | 类型 | 说明 |
|---|---|---|

| workspace_id | varchar(64) | 工作区 ID |
| project_id | varchar(64) | 项目 ID |
| user_id | varchar(64) | 用户 ID |
| event_name | varchar(128) | 埋点事件 |
| source_page | varchar(128) | 来源页面 |
| source_module | varchar(128) | 来源模块 |
| payload | json | 扩展信息 |
| created_at | datetime | 创建时间 |

### 3.12 表：efficiency_snapshot
| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint | 主键 |
| workspace_id | varchar(64) | 工作区 ID |
| project_id | varchar(64) | 项目 ID |
| scene_type | varchar(64) | component-replace |
| baseline_duration_hours | decimal(10,2) | 基线耗时 |
| current_duration_hours | decimal(10,2) | 当前耗时 |
| saved_duration_hours | decimal(10,2) | 节省耗时 |
| estimation_type | varchar(32) | manual / calculated / mixed |
| snapshot_date | date | 快照日期 |

### 3.13 表：pilot_project
| 字段 | 类型 | 说明 |
|---|---|---|
| id | varchar(64) | 主键 |
| workspace_id | varchar(64) | 工作区 ID |
| project_id | varchar(64) | 项目 ID |
| owner | varchar(128) | 负责人 |
| status | varchar(32) | connected / running / archived |
| blocked_count | int | 阻塞数 |
| archived_count | int | 归档数 |
| last_feedback | varchar(512) | 最近反馈 |
| updated_at | datetime | 更新时间 |

### 3.14 表：pilot_review_record
| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint | 主键 |
| workspace_id | varchar(64) | 工作区 ID |
| summary | text | 复盘摘要 |
| current_issues | json | 当前问题 |
| next_recommendations | json | 下一步建议 |
| report_link | varchar(512) | 报告链接 |
| created_at | datetime | 创建时间 |

## 4. 索引建议
- workspace(id)
- project(workspace_id, status)
- run(workspace_id, status, updated_at)
- run_event(run_id, event_type, created_at)
- change_record(workspace_id, updated_at)
- spec_record(workspace_id, updated_at)
- installation_record(workspace_id, created_at)
- dashboard_event_log(workspace_id, event_name, created_at)
- efficiency_snapshot(workspace_id, snapshot_date)
