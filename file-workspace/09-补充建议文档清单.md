# 补充建议文档清单

除了现有文档，我建议继续补齐以下文档，以便把项目从“方案完整”推进到“执行顺畅”。

## 1. 建议补充的文档

### 1.1 《埋点事件字典与枚举值规范》
用途：
- 统一事件名、字段名、枚举值、触发时机
- 降低前后端与测试对齐成本

### 1.2 《首页联调与测试用例执行报告》
用途：
- 记录每轮联调、修复、验证结果
- 形成问题闭环和版本证据

### 1.3 《首页研发排期表（按周 / 按人）》
用途：
- 明确任务负责人、时间计划、依赖关系
- 便于项目推进与汇报

### 1.4 《首页视觉稿说明》
用途：
- 把当前线框稿推进到 UI 层
- 统一视觉风格和组件表现

### 1.5 《组件替换试点模板文档》
用途：
- 快速复制试点场景
- 用真实业务模板验证产品价值

### 1.6 《开发者 10 分钟快速开始文档》
用途：
- 降低首批用户理解成本
- 提高首次接入成功率

### 1.7 《FAQ / 运营话术文档》
用途：
- 用于对内推广、宣讲、试点拉通
- 统一价值表达与常见问题回答

## 2. 推荐优先级

### P0
- 埋点事件字典与枚举值规范
- 首页研发排期表（按周 / 按人）

### P1
- 首页联调与测试用例执行报告
- 组件替换试点模板文档
- FAQ / 运营话术文档

- 首页视觉稿说明

1. 先补《埋点事件字典与枚举值规范》
2. 再补《首页研发排期表（按周 / 按人）》

4. 联调期间产出《首页联调与测试用例执行报告》
5. 试点启动前产出《组件替换试点模板文档》
6. 内部推广前产出《FAQ / 运营话术文档》
