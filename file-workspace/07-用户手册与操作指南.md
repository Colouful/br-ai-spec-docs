# 用户手册 / 操作指南

## 1. 手册目标
帮助首次使用者快速理解：
- BR AI Spec 是什么
- 它适合什么场景
- 如何快速接入
- 如何在首页判断当前状态
- 如何开始一个需求并查看结果

## 2. 产品简介
BR AI Spec 是一套面向团队的 AI 研发规范可观测平台。它包含项目侧底座与团队侧可视化平台两部分，既帮助业务项目完成规范驱动开发，也帮助团队观察接入、运行、阻塞、归档和收益情况。

## 3. 适用人群

### 3.1 开发者
适合希望通过规范提升 AI 代码可接受度、减少返工、保留归档资产的研发人员。

### 3.2 平台管理员
适合需要查看接入情况、试点进度、首页指标与阻塞问题的人员。

## 4. 快速开始

### 第一步：进入首页
登录平台后进入 Dashboard 首页。

### 第二步：查看接入与上手报告
优先查看“接入与上手报告”模块，确认当前项目是否：
- 已安装 Base
- 已联通 Visual
- 已检测到资产
- 已具备开始一个需求的条件

### 第三步：完成项目接入
如果尚未接入，点击“接入当前项目”或“查看 10 分钟快速开始”。

### 第四步：开始一个真实需求
接入完成后，点击“开始一个需求”，选择真实场景，如组件替换需求。

### 第五步：观察运行态与阻塞点
在首页查看运行态健康度、阻塞变化流、最近 Runs 等模块，确认当前需求推进情况。

### 第六步：完成归档并观察结果
首个需求完成归档后，可在首页观察闭环进度与效率收益模块的变化。

## 5. 首页模块说明

### 5.1 接入与上手报告
用于判断是否接入成功、缺少哪些资产、下一步做什么。

### 5.2 运行态健康度
用于查看当前有多少需求在跑、是否存在异常。

### 5.3 交付闭环进度
用于查看需求是否真正从发起走到了归档。

### 5.4 效率收益
用于判断这套体系是否节省了时间、沉淀了资产。

### 5.5 阻塞变化流
用于查看需求为什么卡住，以及卡在哪一步。

### 5.6 规范资产命中情况
用于查看项目是否完整接入了规则、OpenSpec 和运行态资产。

### 5.7 最近 Runs
用于查看最近活跃的需求及其当前阶段。

### 5.8 安装与接入趋势
用于查看整体接入与使用情况。

## 6. 常见操作

### 6.1 开始一个需求
在首页点击“开始一个需求”，按指引进入需求流。

### 6.2 判断本次改动走哪条链
点击“判断本次改动走哪条链”，根据改动范围获得推荐路径。

### 6.3 切换 Workspace
在顶栏切换不同 Workspace，查看不同项目组的数据。

### 6.4 打开 Demo Workspace
如果希望先看示例数据，可打开 Demo Workspace。

### 6.5 查看命令速查
可从首页快捷入口进入命令速查文档，了解常用命令。

## 7. 常见问题

### 7.1 为什么不直接只用 OpenSpec？
OpenSpec 更偏规范与产物本身，BR AI Spec 进一步提供项目接入、运行态观测、试点数据与平台展示能力。

### 7.2 为什么首页没有数据？
通常是因为：
- 当前 Workspace 尚未接入
- Collector 尚未联通
- 还没有发起真实需求
- 数据尚未同步完成

### 7.3 为什么看到资产缺失？
说明平台未完整检测到规则、OpenSpec、`.ai-spec` 或其他关键资产，需要按修复提示处理。

### 7.4 为什么有运行态但没有收益数据？
收益数据通常依赖归档完成和统计口径积累，初期可能不会立即出现。
