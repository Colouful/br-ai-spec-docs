# Three Repo Integration Contract

## 职责边界

| 仓库 | 负责 | 禁止 |
|---|---|---|
| skill-q-platform | 资产源头、Manifest、审核、发布、安装记录、运行效果聚合 | 不直接修改业务项目、不执行项目任务 |
| br-ai-spec | CLI 安装、同步、diff、升级、回滚、本地锁文件 | 不做资产社区运营、不重定义 Hub 模型 |
| br-ai-spec-visual | 项目观测、资产画像、治理看板、运行态回流 | 不做资产源头、不创建 Manifest |

## 数据流

Hub 创建资产和 Manifest → Hub 发布 Manifest Version → CLI 拉取 Manifest Export → CLI 写入业务项目本地文件 → CLI 上报安装记录 → Visual Collector 扫描本地状态 → Visual 回流运行态数据 → Hub 聚合质量指标。

## 单一事实源

Asset / Manifest 定义以 Hub 为准；本地安装状态以 `hub-lock.json` 为准；运行态记录以 `br-ai-spec` / Visual 为准；资产使用统计以 Hub 聚合结果为准。

## 验收标准

Hub 修改 Manifest 后 CLI 能检测差异；CLI 安装后 Visual 展示同一 Manifest ID 和版本；Visual 回流后 Hub 可见使用记录；三仓 AssetKind 和版本字段一致。
