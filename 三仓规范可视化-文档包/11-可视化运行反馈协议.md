# Visual Runtime Feedback Protocol

## 采集来源

`hub-lock.json`、`.agents/registry/`、`.ai-spec/`、`.omx/logs/`、`openspec/`、br-ai-spec run logs。

## 禁止采集

业务源码全文、`.env`、密钥、Token、用户隐私数据、数据库密码。

## RuntimeReport

```ts
interface RuntimeReport {
  projectName: string;
  repoUrl?: string;
  manifestId?: string;
  manifestVersion?: string;
  runId: string;
  stage: 'requirement' | 'design' | 'implement' | 'test' | 'review' | 'archive';
  status: 'success' | 'failed' | 'partial';
  usedAssets: Array<{ kind: string; assetId: string; version: string }>;
  durationMs: number;
  failedReason?: string;
}
```

## 聚合指标

Manifest 安装项目数、使用次数、成功率、Asset 被安装次数、Asset 被使用次数、失败关联次数、平均耗时、常见失败原因、最近活跃项目。
