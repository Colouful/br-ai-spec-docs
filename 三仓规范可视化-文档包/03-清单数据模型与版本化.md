# Manifest Data Model and Versioning

## AssetKind

```ts
type AssetKind = 'skill' | 'rule' | 'role' | 'flow' | 'scenario' | 'template' | 'checklist' | 'adapter' | 'profile';
```

## Manifest 模型

```ts
interface Manifest {
  id: string;
  name: string;
  displayName: string;
  description: string;
  version: string;
  status: 'draft' | 'submitted' | 'approved' | 'published' | 'deprecated' | 'archived';
  techStacks: string[];
  ides: string[];
  scenarios: string[];
  installPolicy: ManifestInstallPolicy;
  compatibility: ManifestCompatibility;
  assets: ManifestAsset[];
}
```

## ManifestAsset

```ts
interface ManifestAsset {
  kind: AssetKind;
  assetId: string;
  version: string;
  required: boolean;
  installPath?: string;
  checksum: string;
  order?: number;
}
```

## 版本规则

统一使用 SemVer：`MAJOR.MINOR.PATCH`。PATCH 可自动升级；MINOR 默认需要确认；MAJOR 禁止自动升级。已发布版本不可修改，只能发布新版本。

## hub-lock.json

安装后必须生成 `hub-lock.json`，包含 hub、manifestId、manifestVersion、manifestChecksum、installedAt、mode、assets、checksum、installPath。Visual 和 CLI diff 都以该文件作为本地状态依据。

## 校验规则

Manifest 发布前必须校验：id 不为空、version 合法、assets 不为空、asset 版本存在、checksum 不为空、不存在重复资产、不存在循环依赖、兼容当前 br-ai-spec 版本。
