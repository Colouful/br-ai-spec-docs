# br-ai-spec Hub Sync Protocol

> 文档状态：V1 可执行版  
> 所属项目：`br-ai-spec` 主导，`skill-q-platform` 提供 API，`br-ai-spec-visual` 读取结果  
> 核心目标：定义 `@ex/ai-spec-auto` 与 Hub 的搜索、安装、同步、差异、升级、回滚协议。

---

## 1. 改造背景

`br-ai-spec` 当前已经具备：

- `npx @ex/ai-spec-auto@latest init .`
- `update .`
- `check .`
- `uninstall .`
- `--profile vue/react`
- `--package packages/web`
- `.agents/rules`、`.agents/skills`、`.cursor`、`.claude`、`openspec` 安装能力
- `/spec-start`、`/spec-update`、`/spec-continue`、`/spec-status` 等执行入口

下一步需要新增 Hub 主路径，让 CLI 可以从 `skill-q-platform` 拉取 Manifest 方案包并安装到业务项目。

## 3. 命令设计

### 3.1 `hub login`

用途：保存 Hub 地址和访问令牌。

```bash
npx @ex/ai-spec-auto hub login --hub http://localhost:3000 --token xxx
```

写入本地：

```text
.ai-spec/config/hub.json
```

结构：

```json
{
  "hub": "http://localhost:3000",
  "tokenSource": "env-or-config",
  "loginAt": "2026-04-24T10:00:00.000Z"
}
```

控制台提示：

```text
Hub 登录成功： http://localhost:3000
后续可直接执行 hub search / hub install / hub sync。
```

---

### 3.2 `hub search`

用途：搜索 Hub 中的资产和方案包。

```bash
npx @ex/ai-spec-auto hub search react
npx @ex/ai-spec-auto hub search react --kind manifest
npx @ex/ai-spec-auto hub search test --kind skill
```

调用接口：

```http
GET /api/hub/search?q=react&kind=manifest
```

输出：

```text
搜索结果：react

1. react-standard-delivery@1.0.0
   类型：Manifest
   适用：React / TypeScript / Cursor
   状态：已发布

2. react-code-style@1.2.0
   类型：Rule
   风险：L0
```

---

### 3.3 `hub install`

用途：安装指定 Manifest 到当前项目。

```bash
npx @ex/ai-spec-auto hub install react-standard-delivery \
  --hub http://localhost:3000 \
  --mode standard \
  --profile react
```

可选参数：

| 参数 | 说明 |
|---|---|
| `--hub` | Hub 地址 |
| `--version` | 指定 Manifest 版本 |
| `--mode` | light / standard / strict / audit-only |
| `--profile` | react / vue / next / custom |
| `--ide` | cursor / claude-code / openclaw |
| `--dry-run` | 只预览，不写入文件 |
| `--force` | 冲突时强制覆盖 |
| `--yes` | 跳过确认 |

执行流程：

```text
1. 读取 Hub 配置
2. 拉取 Manifest Export
3. 校验 Manifest contractVersion
4. 校验资产状态和 checksum
5. 分析当前项目技术栈
6. 计算文件变更计划
7. 展示安装前预览
8. 用户确认
9. 写入 .agents / .cursor / .claude / openspec
10. 写入 hub-lock.json
11. 向 Hub 上报安装记录
12. 输出安装结果
```

---

### 3.4 `hub sync`

用途：同步当前项目已安装 Manifest 的最新兼容版本。

```bash
npx @ex/ai-spec-auto hub sync
```

行为：

- 读取 `.agents/registry/hub-lock.json`。
- 查询 Hub 中同一 Manifest 的最新版本。
- 对 Patch 版本可自动同步。
- 对 Minor / Major 版本输出确认提示。

输出示例：

```text
当前方案包：react-standard-delivery@1.0.0
Hub 最新版本：react-standard-delivery@1.1.0

变更摘要：
- 新增 Skill：generate-test-plan@1.0.0
- 更新 Rule：react-code-style 1.0.0 → 1.1.0

是否同步？输入 y 确认：
```

---

### 3.5 `hub diff`

用途：对比当前本地安装状态与 Hub 发布版本。

```bash
npx @ex/ai-spec-auto hub diff
npx @ex/ai-spec-auto hub diff --version 1.1.0
```

Diff 类型：

| 类型 | 说明 |
|---|---|
| `missing` | 本地缺失 |
| `modified` | 本地被修改 |
| `outdated` | 本地版本落后 |
| `extra` | 本地存在但 Manifest 未声明 |
| `conflict` | 路径冲突或 checksum 冲突 |

输出示例：

```text
差异检查完成：

过期资产：2 个
本地修改：1 个
额外文件：3 个

本地修改：
- .agents/rules/react-code-style/RULE.md
  Hub checksum: sha256:aaa
  Local checksum: sha256:bbb
```

---

### 3.6 `hub upgrade`

用途：升级到指定 Manifest 版本。

```bash
npx @ex/ai-spec-auto hub upgrade --version 1.1.0
```

限制：

- 跨 Major 升级必须二次确认。
- 存在本地修改时，默认不覆盖。
- 使用 `--force` 才允许覆盖冲突文件。

---

### 3.7 `hub rollback`

用途：回滚到历史版本。

```bash
npx @ex/ai-spec-auto hub rollback 1.0.0
```

要求：

- Hub 必须保留目标版本导出数据。
- 本地 `.ai-spec/history/hub-install` 必须记录安装快照。
- 回滚前必须生成备份。

备份路径：

```text
.ai-spec/history/hub-install/<timestamp>/backup/
```

## 4. 本地文件影响范围

`hub install` 允许写入：

```text
.agents/rules/
.agents/skills/
.agents/roles/
.agents/flows/
.agents/registry/
.cursor/
.claude/
openspec/
.ai-spec/config/
.ai-spec/history/
```

禁止直接写入：

```text
src/
package.json
.env
.env.local
node_modules/
.git/
```

如确实需要改 `package.json`，必须进入单独确认步骤，不允许默认写入。

---

## 5. hub-lock.json 协议

路径：

```text
.agents/registry/hub-lock.json
```

CLI 读写规则：

1. 安装成功后必须写入。
2. 同步成功后必须更新。
3. 回滚成功后必须恢复到对应版本。
4. `check` 命令必须校验它的完整性。
5. Visual Collector 只读取，不修改。

## 6. 错误码

| 错误码 | 场景 | 提示 |
|---|---|---|
| `HUB_CONFIG_NOT_FOUND` | 未登录或未指定 Hub | 请先执行 hub login 或使用 --hub 指定地址 |
| `HUB_AUTH_FAILED` | token 无效 | Hub 鉴权失败，请检查访问令牌 |
| `MANIFEST_NOT_FOUND` | 找不到方案包 | 未找到指定 Manifest |
| `MANIFEST_NOT_PUBLISHED` | 方案包未发布 | 当前方案包不可安装 |
| `ASSET_CHECKSUM_MISMATCH` | checksum 不一致 | 资产校验失败，请重新拉取 |
| `LOCAL_FILE_CONFLICT` | 本地文件冲突 | 检测到本地文件已修改，默认不会覆盖 |
| `ROLLBACK_SNAPSHOT_NOT_FOUND` | 回滚快照不存在 | 未找到可回滚版本 |

---

## 7. 幂等性要求

同一个命令重复执行必须满足：

| 命令 | 幂等行为 |
|---|---|
| `hub install` | 已安装同版本时提示“已是最新”，不重复写入 |
| `hub sync` | 无更新时不改文件 |
| `hub diff` | 只读，不写入 |
| `hub upgrade` | 已是目标版本时直接退出 |
| `hub rollback` | 回滚到当前版本时提示无须回滚 |

---

## 10. 验收标准

1. 可以从 Hub 搜索 Manifest。
2. 可以安装 Manifest 到空项目。
3. 可以安装到已存在 `br-ai-spec` 的项目。
4. 本地生成 `hub-lock.json`。
5. 重复安装不重复写入。
6. 本地修改后 `hub diff` 能识别。
7. `hub sync` 能同步 Patch 版本。
8. `hub rollback` 能恢复历史快照。
9. 所有 CLI 输出均为中文。
