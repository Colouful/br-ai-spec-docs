# Database Design

## 表清单

`hub_asset`、`hub_asset_version`、`hub_manifest`、`hub_manifest_version`、`hub_manifest_asset`、`hub_asset_audit_log`、`hub_install_record`、`hub_runtime_report`、`hub_project_registry`、`hub_user`、`hub_team`。

## 核心表字段

`hub_asset`：asset_id、kind、name、display_name、description、owner_id、team_id、status、risk_level、tags。
`hub_manifest`：manifest_id、name、display_name、description、status、tech_stacks、ides、scenarios、tags。
`hub_manifest_version`：manifest_id、version、checksum、install_policy、compatibility、export_snapshot、release_note、status。
`hub_install_record`：project_name、repo_url、manifest_id、manifest_version、install_mode、status、assets、message。
`hub_runtime_report`：project_name、repo_url、manifest_id、manifest_version、run_id、stage、status、used_assets、duration_ms、failed_reason。

## 索引建议

asset_id 唯一索引；manifest_id 唯一索引；manifest_id + version 唯一索引；project_name 普通索引；manifest_id + manifest_version 普通索引。

## 状态枚举

资产和 Manifest 状态：draft、submitted、approved、published、deprecated、archived。安装状态：success、failed、partial、rollback。风险等级：L0、L1、L2、L3、L4。
