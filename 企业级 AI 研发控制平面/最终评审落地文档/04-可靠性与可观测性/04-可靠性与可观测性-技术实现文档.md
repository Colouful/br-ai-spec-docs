# 04 可靠性与可观测性 - 技术实现文档

## 1. 阶段目标

补齐超时、重试、熔断、幂等、checkpoint、resume、abort、clean、metrics 和本地可观测能力。

## 2. 本阶段范围

- 实现 run.log.jsonl 完整事件流
- 实现 checkpoint
- 实现 abort
- 实现 clean
- 实现 resume
- 实现 metrics.json
- 实现命令 timeout 和 retry 策略
- 实现错误码

## 3. 不在本阶段范围内的内容

- 不做远程告警系统
- 不做完整 Visual 大屏
- 不做中心化 Runtime
- 不做分布式队列
- 不做多节点执行

## 4. 前置条件

1. 已阅读 `00-总览/00-AI执行总指令.md`。
2. 已确认前置阶段验收通过。
3. 当前 Git 工作区状态已记录。
4. 当前阶段分支已创建。
5. 如存在【待确认】项，必须先在验收结果文档中记录处理方式。


## 已知资料缺口与处理方式

| 缺失信息 | 影响范围 | 当前处理方式 |

## 7. 目标设计

所有关键步骤写事件日志；外部命令必须有 timeout；失败可 abort；成功或失败都有 metrics。

## 8. 技术实现方案

### 8.1 模块设计

本阶段只实现本阶段范围内的模块。所有新增模块必须保持单一职责，禁止把跨阶段能力提前塞入当前阶段。

### 8.2 接口设计

1. 新增接口必须导出稳定类型。
2. 对外 CLI 行为必须保持中文输出。
3. 内部接口必须支持单元测试。
4. 如修改现有接口，必须提供兼容层或迁移说明。
5. 所有 JSON 文件必须带 `schemaVersion`。

### 8.3 数据结构

1. 阶段运行文件必须写入 `.ai-spec-local/` 或 `~/.br-spec/`。
2. 不确定字段必须使用【待确认】标记，不允许编造。
3. 运行态文件不默认入 Git。
4. 需要入库的规范文件必须由当前阶段明确说明。

### 8.4 配置设计

1. 默认 local-only。
2. 默认关闭 Hub、Visual、多 Agent、多 worktree 并行。
3. 高风险功能必须通过显式配置或命令参数开启。
4. 配置变更必须保留向后兼容。

### 8.5 调用流程

1. 执行前检查 Git 状态。
2. 执行中记录日志。
3. 执行失败写入错误信息。
4. 执行后生成当前阶段要求的输出物。
5. 如遇不可判断问题，写入验收结果文档，不允许静默忽略。

### 8.6 异常处理

1. 不能吞掉异常。
2. 所有错误必须输出中文说明。
3. 可恢复错误必须给出恢复命令。
4. 不可恢复错误必须写入验收结果文档。
5. 不允许为了继续执行而跳过失败检查。

### 8.7 兼容策略

1. 不删除旧入口。
2. 不破坏现有测试。
3. 新能力通过新增模块接入。
4. 必要时增加 adapter，避免直接重写旧逻辑。

### 8.8 回滚策略

1. 当前阶段所有改动应集中在阶段分支。
2. 如阶段失败，优先回滚当前阶段新增代码。
3. 不得回滚前置阶段已验收通过的能力。
4. 如生成运行态文件，使用 clean / abort 或手动删除当前阶段生成文件。

### 8.9 日志要求

1. 关键命令必须有日志。
2. Guard、Test、Evidence、Model 相关事件必须可追踪。
3. 日志不得包含密钥、Token、生产配置。
4. 日志必须能够支撑验收复盘。

### 8.10 权限要求

1. 不读取敏感文件。
2. 不修改生产配置。
3. 不执行破坏性 Git 操作，除非文档明确要求。
4. 高风险操作必须人工确认。

- src/cli

## 10. AI 编程模型执行指令

你现在执行第 04 阶段：【可靠性与可观测性】。

请先阅读以下三个文档：

1. `04-可靠性与可观测性-技术实现文档.md`
2. `04-可靠性与可观测性-测试文档.md`
3. `04-可靠性与可观测性-验收结果文档.md`

你的任务是：

1. 理解本阶段目标和边界。
2. 只修改本阶段允许修改的文件和模块。
3. 按照技术实现文档完成开发。
4. 按照测试文档执行测试。
5. 将真实测试结果写入验收结果文档。
6. 判断是否满足进入下一阶段的条件。

严格禁止：

1. 扩大范围。
2. 跳过测试。
3. 删除测试。
4. 伪造结果。
5. 修改无关模块。
6. 引入未说明的大型依赖。
7. 破坏向后兼容。

完成后请输出：

1. 修改文件清单。
2. 实现摘要。
3. 执行的测试命令。
4. 测试结果。
5. 验收结果。
6. 遗留问题。
7. 是否建议进入下一阶段。
