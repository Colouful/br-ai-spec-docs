# B1.4-SchemaExport与Fixture输出-测试文档

## 1. 测试目标

验证 br-ai-spec 已输出跨仓库协议 schema(模式)与 fixture(样例数据)，并可被 Node.js 测试读取。

## 2. 测试命令

1. `node tests/contracts/schema-export.test.js`
2. `npm run test:registry`
3. `npm run test:runtime`
4. `npm run verify:p5`

## 3. 通过标准

1. 5 类协议均有 schema 与 fixture。
2. 每个 fixture 包含 schema 必填字段。
3. `run-event.schema.json` 已补齐。
4. Fixture 不包含密钥、原始 Prompt、完整源码或敏感日志。
