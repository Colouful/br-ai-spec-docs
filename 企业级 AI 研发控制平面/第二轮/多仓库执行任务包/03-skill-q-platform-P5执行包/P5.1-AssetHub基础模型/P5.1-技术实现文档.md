# P5.1-AssetHub基础模型-技术实现文档

## 1. 阶段目标

在 skill-q-platform 中建立统一 Asset 基础模型，支持 Rule / Skill / Agent Profile / Workflow / Hook / Command。

## 2. 目标仓库

`skill-q-platform`

## 3. 本阶段范围

复用现有 Skill / Rule / Manifest / Agent Profile 数据结构，不重复造轮子。

## 4. 不在本阶段范围内的内容

不实现 br-ai-spec CLI；不实现 Visual Run Timeline。

## 5. 前置条件

1. 已阅读根目录 `README.md`。
2. 已阅读 `00-多仓库职责边界说明.md`。
3. 已确认当前仓库为 `skill-q-platform`。
4. 已创建本阶段独立开发分支。
5. 如依赖其他仓库输出，必须使用本包提供的 Schema / Fixture，不允许自行臆造协议。

## 6. 相关模块与文件

建议文件定位：models、prisma/schema、services/assets、api/assets，实际位置【待确认】。

如果无法确定具体文件，请基于项目结构定位并在进度同步文档中标记【待确认】。

## 7. 当前问题

1. `br-ai-spec` 已经执行过 P0-P5，但 Visual 和 Hub 仓库尚未完成对应主体能力。
2. P4 / P5 不能继续在单仓库中闭门实现。
3. 后续必须先完成边界收口，再补连接器、Visual 观测、Hub 资产中心和四仓联调。

## 8. 目标设计

1. 当前阶段职责只落在指定仓库。
2. 与其他仓库通过明确 Schema / API / Fixture 对接。
3. 变更可测试、可验收、可回滚。
4. 不污染业务项目，不存储敏感数据。
5. 所有真实测试和验收结果必须由执行模型在执行后填写。

## 9. 技术实现方案

### 9.1 模块设计

围绕 `AssetHub基础模型` 建立最小可用实现，优先复用现有模块；不存在时再新增最小实现。

### 9.2 接口设计

涉及跨仓库时优先使用本包 `05-跨仓库协议与样例数据/` 下的 Schema。接口必须保持稳定、向后兼容。

### 9.3 数据结构

所有结构化数据必须包含版本字段、时间字段、来源字段和兼容策略。严禁无版本裸结构跨仓库传输。

### 9.4 配置结构

配置必须支持默认值。敏感配置必须来自环境变量或用户本地配置，不允许写入 Git。

### 9.5 文件结构

新增文件必须放在本阶段允许范围内；如果现有项目已有同类目录，必须复用。

### 9.6 调用流程

读取配置 → 校验输入 → 执行业务逻辑 → 输出结构化结果 → 写日志 / 事件 → 返回结果。

### 9.7 异常处理

必须区分参数错误、权限错误、依赖不可用、数据不兼容、执行失败和未知错误。

### 9.8 兼容策略

新增字段必须可选；删除字段必须保留兼容读取；接口变更必须支持旧版本最小读取。

### 9.9 回滚策略

所有新增文件可通过 Git 回滚；数据库变更必须有迁移回滚说明；配置变更必须能恢复默认值。

### 9.10 日志要求

日志必须记录阶段编号、仓库、操作、结果、错误摘要，不记录密钥、原始 Prompt、完整源码。

### 9.11 权限要求

涉及写操作、发布、回滚、审计、上报时必须进行权限或配置校验。

### 9.12 安全要求

必须脱敏敏感字段；不得上传源码；不得存储原始 Prompt；不得绕过 Hook / Policy / Test。

### 9.13 测试影响范围

测试必须覆盖本阶段新增或修改的核心流程，至少包含成功路径、失败路径和回滚路径。


## 字段与 JSON 结构要求

### AssetPackage

| 字段名 | 字段类型 | 是否必填 | 默认值 | 字段说明 | 示例值 | 校验规则 | 兼容策略 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| assetId | string | 是 | 无 | 资产 ID | rule.react.basic | 非空 | 稳定 |
| assetType | string | 是 | 无 | 资产类型 | rule | rule/skill/agentProfile/workflow/hook/command | 新增类型向后兼容 |
| name | string | 是 | 无 | 资产名称 | React 基础规范 | 非空 | 稳定 |
| version | string | 是 | 0.1.0 | 语义化版本 | 1.0.0 | semver | 保持语义化 |
| source | string | 是 | hub | 来源 | skill-q-platform | 非空 | 稳定 |
| checksum | string | 是 | 无 | 内容校验 | sha256:xxx | sha256 | 用于防篡改 |
| compatibility | object | 否 | {} | 兼容信息 | {} | 可选 | 旧版本忽略 |
| files | array | 是 | [] | 资产文件列表 | [] | 路径合法 | 不包含运行态数据 |
| metadata | object | 否 | {} | 扩展信息 | {} | 可 JSON 序列化 | 不可含敏感信息 |

JSON 示例：

```json
{
  "assetId": "rule.react.basic",
  "assetType": "rule",
  "name": "React 基础规范",
  "version": "1.0.0",
  "source": "skill-q-platform",
  "checksum": "sha256:example",
  "compatibility": {
    "adapters": [
      "cursor",
      "claudeCode"
    ],
    "frameworks": [
      "react"
    ]
  },
  "files": [
    {
      "path": "rules/react-basic.md",
      "checksum": "sha256:file"
    }
  ],
  "metadata": {
    "owner": "platform-team"
  }
}
```
