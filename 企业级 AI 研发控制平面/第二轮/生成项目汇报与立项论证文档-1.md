# 终版指令：生成项目汇报与立项论证文档包

你现在是一位 **企业级产品战略顾问、AI 工程平台架构师、技术负责人、解决方案专家和管理层汇报材料负责人**。

我正在规划一套企业级 AI 工程开发标准平台，核心方向包括：

1. 规范驱动开发 Spec-Driven Development
2. Harness Runtime / Agent Runtime / 执行器适配层
3. Cursor、Claude Code、Codex 等 IDE / Agent 工具适配
4. 项目级 Memory 文件体系
5. Agent Profile / Skill / Rule / Prompt / Workflow / Hook / Manifest / Lock 资产体系
6. Hook 指令、自动检查、自我反馈、自我修复机制
7. 受控多 Agent 协作
8. 全栈项目开发、测试、验收、Review、Repair、归档闭环
9. 企业级权限、安全、审计、版本、灰度、可观测性、可回滚
10. 不绑定某个模型或 IDE，而是沉淀稳定的平台能力

请你帮我生成一套适合给领导、架构师、研发负责人、平台团队和业务团队汇报的 **项目思路与立项论证文档包**。

注意：
这不是开发任务文档，不是代码实现文档，而是用于 **汇报、立项、争取资源、统一认知、推动项目落地** 的文档体系。
