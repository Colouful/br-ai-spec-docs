## 8. 技术实现方案

### 8.1 模块设计

- 输入层：读取当前项目配置、阶段文档和必要上下文。
- 处理层：按本阶段任务实现具体能力。
- 输出层：写入目标文件、配置、测试结果或报告。
- 记录层：写入进度同步与验收模板。

### 8.2 接口设计

如涉及 CLI，推荐接口：

```bash
br-spec init\nbr-spec status\nbr-spec check --stage <stage>\nbr-spec repair --run <runId>\nbr-spec report --run <runId>
```

如涉及 TypeScript 模块，推荐接口：

```ts
export interface StageExecutor {\n  execute(input: StageInput): Promise<StageResult>;\n  validate(result: StageResult): Promise<ValidationResult>;\n  rollback(context: RollbackContext): Promise<RollbackResult>;\n}
```

### 8.4 文件结构

项目内只允许写入规范资产和适配文件；运行态、缓存、日志、上下文、密钥必须写入 `~/.ai-spec-auto/`。

```text
project-root/\n  .ai-spec/\n  .agents/\n  .cursor/\n  .claude/\n  .memory/\n  .harness/\n~/.ai-spec-auto/projects/{projectId}/\n  runs/ cache/ logs/ context/ repair/ secrets/
```

### 8.5 调用流程

1. 读取阶段输入。
2. 校验前置条件。
3. 执行具体开发任务。
4. 生成或修改目标文件。
5. 运行测试命令。
6. 写入真实测试结果。
7. 更新进度同步。
8. 判断是否允许进入下一阶段。

### 8.6 异常处理

- 配置缺失：输出【待确认】，不得编造。
- 测试失败：记录失败，进入待修复。
- 权限不足：标记阻塞。
- 目录写入失败：回滚已创建文件并记录。
- Schema 校验失败：禁止进入下一阶段。

### 8.7 兼容策略

1. 不删除已有配置。
2. 新增字段必须有默认值。
3. 已存在文件需备份或通过 diff 方式修改。
4. 生成文件必须可重复生成。
5. Codex 相关能力只保留协议，不强制实现。

### 8.8 回滚策略

1. 使用 Git 恢复被修改文件。
2. 删除本阶段新增生成文件。
3. 恢复 `.ai-spec/ai-spec.lock` 到阶段前状态。
4. 删除 `~/.ai-spec-auto/projects/{projectId}/runs/{runId}` 中本次运行记录，或标记为 rolled_back。
5. 重新运行回滚验证命令。

### 8.9 日志要求

- 只能记录脱敏后的摘要。
- 不得记录密钥、原始 Prompt、完整源码、敏感接口响应。
- 错误日志必须包含 runId、stage、errorCode、message、timestamp。

### 8.10 权限要求

- AI 执行模型只能修改本阶段允许文件。
- 修改长期 Memory 必须生成提案，不得自动合入。
- 禁止越权修改 `.env*`、secrets、CI 密钥和发布配置。

### 8.11 安全要求

- 运行态数据不得进入 Git。
- Prompt、日志和测试输出需要脱敏。
- Shell 命令必须走白名单或阶段文档明确允许。
- 不允许绕过 Hook、测试和验收。

### 8.12 测试影响范围

本阶段测试影响范围以测试文档为准，至少覆盖配置、生成文件、异常场景和回滚验证。

## 14. 风险与回滚方案

| 主要风险 | 触发条件 | 影响范围 | 回滚方式 | 回滚验证命令 |
| ---- | ---- | ---- | ---- | ---- |
| 误改无关模块 | diff 中出现非本阶段文件 | 项目稳定性 | git restore 非本阶段文件 | git diff --name-only |
| 生成文件格式错误 | JSON/Markdown 校验失败 | 适配器不可用 | 恢复上一个 lock 并重新生成 | npm test 或 pnpm test |
| 运行态进入项目仓库 | Git 发现 runs/cache/logs/secrets | 安全与仓库污染 | 删除污染目录并修复写入路径 | git status --ignored |
| 测试失败 | 测试命令非 0 | 阶段无法验收 | 修复后重测或回滚 | 测试文档指定命令 |
