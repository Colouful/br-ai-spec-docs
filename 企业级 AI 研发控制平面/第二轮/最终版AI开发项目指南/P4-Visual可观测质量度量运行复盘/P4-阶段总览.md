# P4-阶段总览：Visual 可观测、质量度量、运行复盘

## 1. 阶段目标

让每次 AI 开发任务可视化、可度量、可复盘、可优化。

## 2. 阶段边界

覆盖 Event Gateway、Run Timeline、Hook/Test/Repair 可视化、Agent 协作可视化、指标趋势、风险审计看板和 P4 验收。

## 3. 不在本阶段范围内的内容

| 禁止范围 |
| ---- |
| 上传完整源码 |
| 展示完整 Prompt 原文 |
| 替代 Sentry/DevOps |
| 做业务 BI 平台 |


## 4. 小阶段拆分

| 小阶段编号 | 小阶段名称 | 小阶段目标 |
| ---- | ---- | ---- |
| P4.1 | EventGateway | 实现运行事件接收、校验、脱敏、存储和查询。 |
| P4.2 | RunTimeline | 实现单次 Run 的时间线聚合与展示数据结构。 |
| P4.3 | Hook-Test-Repair可视化 | 展示 Hook、Test、Repair 结果，支持失败原因和修复次数分析。 |
| P4.4 | Agent协作可视化 | 展示 Agent 调用、handoff、冲突、人工门禁和结论。 |
| P4.5 | 质量指标与趋势分析 | 统计任务成功率、首次通过率、修复成功率、Hook 失败率、Rule 命中率等指标。 |
| P4.6 | 风险与审计看板 | 展示策略拒绝、安全风险、越权尝试、审计操作。 |
| P4.7 | P4集成回归与阶段验收 | 验证事件上报、可视化页面、指标、风险看板和复盘能力。 |

## 8. 核心数据结构

| 结构 | 用途 |
| ---- | ---- |
| Manifest | 统一声明 Rule、Skill、Agent Profile、Command、Hook、Adapter、Memory、Spec |
| Lock | 锁定资产版本、checksum、生成文件和适配输出 |
| Local State | 描述用户本机运行态目录和项目映射 |
| Run Event | 描述运行事件、Hook 事件、测试事件、修复事件 |
| Evidence Report | 描述一次任务的最终证据链 |
| Hook Config | 描述 Hook 生命周期、命令、阻塞策略和输出位置 |
| Agent Profile | 描述 Agent 身份、职责、权限、上下文边界和升级策略 |

## 10. 测试策略

1. 每个小阶段先执行单元测试或配置校验。
2. 涉及 CLI 的阶段执行命令行集成测试。
3. 涉及目录和生成文件的阶段执行快照或文件存在性校验。
4. 涉及安全与权限的阶段执行异常与越权测试。
5. 集成回归阶段执行完整端到端验证。

## 11. 验收策略

每个小阶段验收结果文档默认均为模板状态。真实执行后才能填写通过或失败。阶段验收必须汇总小阶段验收结果。

## 12. 风险与回滚策略

| 风险 | 回滚策略 |
| ---- | ---- |
| 生成文件破坏现有项目 | 删除生成文件并恢复 Git 状态 |
| 配置格式错误 | 恢复上一版本配置和 lock |
| 运行态写入项目仓库 | 删除污染目录并修复 Local State 写入策略 |
| 测试失败 | 进入待修复状态，修复后重新测试 |
| 无法判断 | 标记阻塞并记录待确认信息 |


## 13. 阶段完成标准

1. 本阶段所有小阶段验收通过。
2. 必要测试真实执行并记录。
3. 无阻塞问题。
4. 回滚策略可执行或已记录待确认。
5. 阶段进度同步文档已更新。
