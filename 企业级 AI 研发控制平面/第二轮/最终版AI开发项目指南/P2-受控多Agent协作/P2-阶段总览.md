# P2-阶段总览：受控多 Agent 协作

## 1. 阶段目标

引入专业 Agent 分工，但由 Harness 控制权限、上下文、文件范围、修复次数和人工门禁。

## 2. 阶段边界

覆盖 Agent Profile、权限模型、上下文边界、协作协议、Review/Repair 闭环、冲突处理和 P2 集成验收。

## 3. 不在本阶段范围内的内容

| 禁止范围 |
| ---- |
| 完全自主多 Agent 公司 |
| Agent 自由创建 Agent |
| Agent 自动上线 |
| Agent 自动写长期 Memory |


## 4. 小阶段拆分

| 小阶段编号 | 小阶段名称 | 小阶段目标 |
| ---- | ---- | ---- |
| P2.1 | AgentProfileSchema | 定义 Agent Profile Schema，包括职责、工具权限、文件范围、Memory 访问、最大迭代次数和升级策略。 |
| P2.2 | Agent权限模型 | 实现 allowedTools、deniedTools、allowedFileScopes、deniedFileScopes 权限校验。 |
| P2.3 | Agent上下文边界 | 实现 Agent 上下文装配策略，限制每类 Agent 读取的 Spec、Memory、代码范围和运行事件。 |
| P2.4 | Agent协作协议 | 定义 Agent 协作消息、任务交接、结果声明、依赖关系和状态流转。 |
| P2.5 | Review-RepairAgent闭环 | 实现 Review Agent 输出问题清单，Repair Agent 受限修复并受 maxRepairAttempts 控制。 |
| P2.6 | 多Agent冲突处理与人工门禁 | 实现 Agent 结论冲突检测、争议记录、人工门禁和继续/终止决策。 |
| P2.7 | P2集成回归与阶段验收 | 完成受控多 Agent 端到端回归，验证权限、上下文、协作、冲突、修复和人工门禁。 |

## 8. 核心数据结构

| 结构 | 用途 |
| ---- | ---- |
| Manifest | 统一声明 Rule、Skill、Agent Profile、Command、Hook、Adapter、Memory、Spec |
| Lock | 锁定资产版本、checksum、生成文件和适配输出 |
| Local State | 描述用户本机运行态目录和项目映射 |
| Run Event | 描述运行事件、Hook 事件、测试事件、修复事件 |
| Evidence Report | 描述一次任务的最终证据链 |
| Hook Config | 描述 Hook 生命周期、命令、阻塞策略和输出位置 |
| Agent Profile | 描述 Agent 身份、职责、权限、上下文边界和升级策略 |

## 10. 测试策略

1. 每个小阶段先执行单元测试或配置校验。
2. 涉及 CLI 的阶段执行命令行集成测试。
3. 涉及目录和生成文件的阶段执行快照或文件存在性校验。
4. 涉及安全与权限的阶段执行异常与越权测试。
5. 集成回归阶段执行完整端到端验证。

## 11. 验收策略

每个小阶段验收结果文档默认均为模板状态。真实执行后才能填写通过或失败。阶段验收必须汇总小阶段验收结果。

## 12. 风险与回滚策略

| 风险 | 回滚策略 |
| ---- | ---- |
| 生成文件破坏现有项目 | 删除生成文件并恢复 Git 状态 |
| 配置格式错误 | 恢复上一版本配置和 lock |
| 运行态写入项目仓库 | 删除污染目录并修复 Local State 写入策略 |
| 测试失败 | 进入待修复状态，修复后重新测试 |
| 无法判断 | 标记阻塞并记录待确认信息 |


## 13. 阶段完成标准

1. 本阶段所有小阶段验收通过。
2. 必要测试真实执行并记录。
3. 无阻塞问题。
4. 回滚策略可执行或已记录待确认。
5. 阶段进度同步文档已更新。
