# 00-最终方案执行总览

## 1. 最终开发目标

建设一套企业级 AI 工程开发标准平台，让 AI 开发按照项目规范完成可控、可测、可验收、可追踪、可回滚的工程交付。

## 2. 平台核心定位

让 AI 开发按照项目规范完成可控、可测、可验收、可追踪、可回滚的工程交付。

## 3. 总体架构方向

总体采用“项目内轻量规范资产 + 用户本地运行态 + 企业平台治理态”的三层架构。

```text
项目仓库：.ai-spec / .agents / .cursor / .claude / .memory / .harness\n用户目录：~/.ai-spec-auto/projects/{projectId}/runs cache logs context repair secrets\n平台服务：Asset Hub / Visual / Admin Console / Audit / Policy
```

## 4. P0-P5 分阶段路线

| 阶段 | 阶段名称 | 目标 |
| ---- | ---- | ---- |
| P0 | Cursor + Claude Code 双 IDE 项目级最小闭环 | 让单个项目在 Cursor 与 Claude Code 中基于同一套规范资产完成一次可检查、可修复、可归档的 AI 开发任务闭环。 |
| P1 | 多项目标准化与 Adapter Protocol | 让同一套规范资产可复制到多个项目，并固化 IDE Adapter Protocol、Asset Package 标准和配置分层。 |
| P2 | 受控多 Agent 协作 | 引入专业 Agent 分工，但由 Harness 控制权限、上下文、文件范围、修复次数和人工门禁。 |
| P3 | 企业级治理、权限、审计、灰度、回滚 | 把工具升级为企业可管理、可审计、可灰度、可回滚的平台能力。 |
| P4 | Visual 可观测、质量度量、运行复盘 | 让每次 AI 开发任务可视化、可度量、可复盘、可优化。 |
| P5 | Asset Hub、组织级资产复用 | 建立企业级 Rule、Skill、Agent Profile、Workflow、Hook、Command 资产中心，支持搜索、安装、升级、回滚、继承、Fork、评分和反馈闭环。 |


## 5. 大阶段、小阶段、小任务之间的关系

- 大阶段定义产品能力成熟度。
- 小阶段定义可独立交给 AI 编程模型执行的开发包。
- 小功能任务定义具体文件、结构、接口、测试和验收。
- 每个小阶段必须包含技术实现、测试、验收结果模板、进度同步四类文档。

## 6. 阶段依赖关系

P0 是所有后续阶段基础。P1 依赖 P0 的目录治理、Manifest、Adapter 和闭环。P2 依赖 P1 的协议化能力。P3 依赖 P2 的资产、Agent、运行事件边界。P4 依赖 P3 的事件、审计、策略数据。P5 依赖 P4 的质量反馈数据。

## 7. 总体技术边界

- P0 不做 Codex 完整适配。
- P0 不做完整多 Agent Runtime。
- P0 不做企业多租户。
- P0 不做复杂 Visual 平台。
- P0 不做资产市场。
- 任意阶段不得将运行态数据、密钥、原始 Prompt、敏感日志提交到 Git。

## 8. 总体风险

| 风险 | 影响 | 控制策略 |
| ---- | ---- | ---- |
| 阶段范围膨胀 | 导致无法落地 | 严格按小阶段执行，禁止跨阶段修改 |
| 目录污染业务项目 | 团队接受度下降 | 运行态全部进入 ~/.ai-spec-auto/ |
| Memory 污染 | 后续任务错误累积 | 长期 Memory 只允许 Review 后合入 |
| 多 Agent 失控 | 权限和上下文越界 | Harness 控制权限、文件范围和迭代次数 |
| 测试结果伪造 | 平台可信度丧失 | 验收文档默认待执行，真实执行后填写 |


## 9. 总体验收标准

1. P0 能完成 Cursor + Claude Code 双 IDE 单项目闭环。
2. P1 能完成多项目复制接入。
3. P2 能完成受控多 Agent 协作。
4. P3 能完成企业级权限、审计、灰度、回滚。
5. P4 能完成运行态可观测与复盘。
6. P5 能完成资产中心与组织级复用。
7. 所有阶段测试和验收结果必须真实记录。

## 10. 最终交付物清单

- CLI 与 Harness Runtime
- Cursor Adapter
- Claude Code Adapter
- Codex Adapter Protocol
- Manifest / Lock / Asset Package 标准
- Memory / Hook / Agent Profile 规范
- Hook / Test / Repair / Evidence 闭环
- RBAC / Audit / Policy / Gray / Rollback
- Visual Run Timeline 与质量指标
- Asset Hub 与质量反馈闭环
