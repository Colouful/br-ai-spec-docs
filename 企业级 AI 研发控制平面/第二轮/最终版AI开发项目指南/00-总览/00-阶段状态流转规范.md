# 00-阶段状态流转规范

## 1. 正常流转

未开始 → 执行中 → 待测试 → 待验收 → 已完成

## 2. 测试失败流转

待测试 → 测试失败 → 待修复 → 待测试

## 3. 验收失败流转

待验收 → 验收失败 → 待修复 → 待测试

## 4. 阻塞流转

执行中 → 已阻塞
测试失败 → 已阻塞
验收失败 → 已阻塞

## 5. 回滚流转

执行中 → 已回滚
测试失败 → 已回滚
验收失败 → 已回滚

## 6. 状态更新要求

每次状态变化必须同步更新：

1. 当前小阶段进度同步文档。
2. 当前大阶段任务进度同步文档。
3. `00-任务进度同步总表.md`。

## 7. 禁止状态跳转

- 未开始不得直接跳到已完成。
- 测试失败不得直接跳到已完成。
- 验收失败不得直接跳到已完成。
- 已阻塞恢复后必须进入执行中或待修复。
- 已回滚后必须重新评估是否重新执行。
