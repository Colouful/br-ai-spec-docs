# 00-目录与文件命名规范

## 1. 根目录

所有文档必须位于 `project-execution-docs/` 根目录下。

## 2. 阶段目录命名

格式：

`P{阶段号}-{阶段中文名称}/`

示例：

`P0-Cursor-ClaudeCode双IDE项目级最小闭环/`

## 3. 小阶段目录命名

格式：

`P{大阶段}.{小阶段}-{小阶段中文名称}/`

示例：

`P0.2-项目初始化与目录治理/`

## 4. 小阶段文件命名

每个小阶段必须包含：

- `P0.2-技术实现文档.md`
- `P0.2-测试文档.md`
- `P0.2-验收结果文档.md`
- `P0.2-进度同步文档.md`

## 5. 项目内目录命名

推荐项目内目录：

- `.ai-spec/`
- `.agents/`
- `.cursor/`
- `.claude/`
- `.memory/`
- `.harness/`
- `openspec/`
- `docs/`
- `tests/`
- `reports/`

## 6. 用户本机目录命名

推荐用户本机目录：

`~/.ai-spec-auto/projects/{projectSlug}-{projectHash}/`

其中：

- `projectSlug` 来源于 package.json name、git repo 名或目录名。
- `projectHash` 来源于项目绝对路径 sha256 前 8 位。

## 7. 禁止命名

- 禁止使用含密钥、用户隐私、业务敏感信息的目录名。
- 禁止将运行态数据放入项目 Git 跟踪目录。
- 禁止用“临时最终版”“新建文件夹”等不可维护名称。
