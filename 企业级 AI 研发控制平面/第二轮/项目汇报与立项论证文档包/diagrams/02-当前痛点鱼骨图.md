# 当前痛点鱼骨图


```mermaid
flowchart LR
    P[AI 开发不可控] --> A[人]
    P --> B[流程]
    P --> C[工具]
    P --> D[资产]
    P --> E[治理]
    A --> A1[成员 Prompt 经验割裂]
    A --> A2[新人不懂项目规范]
    B --> B1[缺少 Spec / DoD]
    B --> B2[缺少测试验收闭环]

    C --> C2[IDE 原生规则不统一]

    D --> D2[经验无法复用]
    E --> E1[无审计]

```
