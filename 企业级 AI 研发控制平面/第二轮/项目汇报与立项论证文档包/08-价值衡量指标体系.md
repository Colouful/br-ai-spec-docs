# 价值衡量指标体系

## 1. 北极星指标

规范驱动 AI 任务成功率。

定义：在 AI 参与的开发任务中，按 Spec / Test Plan / DoD 完成开发，并通过测试、Review 和验收的任务占比。

## 2. 指标体系树

详见 `diagrams/16-指标体系树.md`。

## 4. P0-P5 每阶段指标目标

| 阶段 | 重点指标 | 目标 |
| --- | --- | --- |
| P0 | AI 任务完成率、首次测试通过率、双 IDE 一致性、Evidence 完整率 | 证明最小闭环有效 |
| P1 | 多项目接入耗时、资产复用率、Adapter 校验通过率 | 证明可复制 |
| P2 | Agent 成功率、平均修复次数、人工介入次数 | 证明多 Agent 有收益 |
| P3 | 审计覆盖率、权限命中率、资产锁定率、回滚成功率 | 证明企业治理可用 |
| P4 | 指标采集完整率、Run 可复盘率、风险识别率 | 证明可观测 |
| P5 | 资产复用率、资产评分、跨团队使用率 | 证明组织资产化 |

## 5. ROI 计算模型

ROI = 可量化收益 - 平台建设成本 - 维护推广成本。

可量化收益可包含需求开发时间节省、Review 时间节省、缺陷修复成本下降、跨项目资产复用节省和安全风险暴露降低。
