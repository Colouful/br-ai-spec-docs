# V0.1 → V1.0 路线图

---

## 1. 阶段总览

```text
V0.1：本地控制闭环
V0.2：资产治理增强
V0.3：Visual 观测增强
V0.4：IDE Adapter 完善
V0.5：企业试点
V1.0：团队级推广
```

---

## 2. V0.1：本地控制闭环

目标：跑通中台金融系统标准需求的完整链路。

必须交付：

1. `br-spec init/plan/run/verify/report/resume/clean/worktree`。
2. OpenSpec L2/L3 支持。
3. Context Pack。
4. Task DAG。
5. Git worktree。
6. Executor Pool。
7. Hook / Test Gate。
8. Evidence。
9. Visual 最小上报。

验收标准：

- “新增产品配置管理模块”样板需求能完整跑通。
- 至少 3 个并行 Task 能通过 worktree 隔离执行。
- 测试失败能触发最多 3 轮修复。
- final-report 与 evidence-index 完整生成。

---

## 3. V0.2：资产治理增强

目标：skill-q-platform 具备企业资产管理能力。

能力：

1. Manifest 管理。
2. Rule 管理。
3. Skill 管理。
4. Agent Profile 管理。
5. Hook Spec 管理。
6. Test Gate 管理。
7. 资产审核与发布。
8. CLI 资产同步。

验收标准：

- CLI 可从 Hub 拉取资产包。
- 资产版本可锁定。
- 资产变更可审计。

---

## 4. V0.3：Visual 观测增强

目标：br-ai-spec-visual 从事件展示升级为研发观测面板。

能力：

1. Run 时间线。
2. Task DAG 可视化。
3. Agent 执行轨迹。
4. worktree 状态。
5. Patch 合并结果。
6. 测试结果趋势。
7. 自修复统计。
8. 证据浏览器。

验收标准：

- 技术负责人可通过 Visual 复盘一次完整 AI 交付。
- 可定位失败 Task 和失败测试。
- 可查看证据链接。

---

## 5. V0.4：IDE Adapter 完善

目标：统一适配 Cursor、Claude Code、Codex。

能力：

1. Cursor Rules 生成。
2. Claude `CLAUDE.md` / `.claude` 生成。
3. Codex `AGENTS.md` 生成。
4. 项目级 Memory 同步。
5. Hook 能力适配。
6. IDE 指令模板统一。

验收标准：

- 同一个 Manifest 能生成三类 IDE 配置。
- 同一个需求在不同 IDE 中使用同一套规范。

---

## 6. V0.5：企业试点

目标：选择 1-2 个真实业务项目试点。

试点标准：

1. 真实 Vue + Spring Boot 项目。
2. 有中等复杂度配置类需求。
3. 团队愿意提供反馈。
4. 有测试命令或可补齐测试命令。

验收标准：

- 完成不少于 3 个 L2 需求。
- 统计 AI 采纳率、测试通过率、自修复成功率。
- 收集团队反馈。

---

## 7. V1.0：团队级推广

目标：成为团队级 AI 研发标准平台。

能力：

1. 多项目资产下发。
2. 团队规范版本管理。
3. Run 指标统计。
4. 质量报告。
5. 失败样本反哺 Skill / Rule。
6. 权限与审计。
7. 企业级最佳实践库。

验收标准：

- 支持多个业务项目接入。
- 支持团队规范统一升级。
- 支持管理层查看 AI 研发效能指标。

---

## 8. 建议排期

|---|---:|---|
| V0.1 | 4-6 周 | 本地闭环、样板跑通 |
| V0.2 | 3-4 周 | Hub 资产治理 |
| V0.3 | 3-4 周 | Visual 观测 |

| V0.5 | 4 周 | 真实项目试点 |

---

## 9. 阶段性取舍建议

### 必须优先

1. br-ai-spec 本地闭环。
2. OpenSpec + Task DAG。
3. Git worktree。
4. Test Gate。
5. Evidence。

### 可以后置

1. 复杂 RBAC。
2. 资产市场。
3. 复杂大屏。
4. 自动上线。
5. 多租户商业化。

---

## 10. 最终建议

第一阶段不要追求“平台看起来完整”，而要追求：

```text
一个真实中台金融系统需求，能被 AI 按企业流程稳定交付，并留下完整证据。
```

只要这个闭环跑通，后续 Hub、Visual、IDE Adapter 都是自然扩展。
