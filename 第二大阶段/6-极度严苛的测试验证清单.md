# 六、极度严苛的测试验证清单

> 本章节用于约束 Cursor / Claude Code / Codex IDE Agent 在完成开发后必须执行的测试。
> 所有测试必须覆盖：
>
> 1. 单元测试。
> 2. 集成测试。
> 3. 执行器切换测试。
> 4. 异常与边界测试。
> 5. 隐私与安全测试。
> 6. 性能与稳定性测试。
>
> 测试框架建议：
>
> * `br-ai-spec`：`vitest`
> * `skill-q-platform`：`vitest + supertest / Next API route test`
> * `br-ai-spec-visual`：`vitest + Playwright`
> * CLI 集成测试：真实临时目录 + fixture 项目
> * Git / Worktree 测试：临时 Git 仓库，不使用真实业务仓库

---

# 6.1 测试总原则

## 6.1.1 不允许跳过 P0 测试

以下能力必须全部测试通过后，才能继续 P1 / P2 / P3：

```text
1. 配置加载优先级。
2. 扫描引擎只读。
3. Workspace / Package 识别。
4. Manifest 推荐输入输出。
5. ai-spec.lock.json 生成。
6. registry.index.json 生成。
7. context-index.json 生成。
8. 全局缓存同步。
9. checksum 防篡改。
10. dirty working tree 策略。
11. branch / worktree 创建。
12. 状态机合法流转。
13. 熔断机制。
14. Context Builder 渐进式加载。
15. PrivacyFilter 隐私过滤。
```

---

## 6.1.2 测试不得依赖真实用户项目

所有测试必须基于 fixture：

```text
br-ai-spec/tests/fixtures/
├── react-vite/
├── nextjs-app-router/
├── vue-vite/
├── springboot-maven/
├── springboot-gradle/
├── monorepo-pnpm/
├── multi-repo-workspace/
├── dirty-git-repo/
├── tampered-assets/
└── malformed-config/
```

---

## 6.1.3 扫描测试不得写入业务文件

对扫描引擎的测试必须 mock 或 spy：

```ts
vi.spyOn(fs, 'writeFile');
vi.spyOn(fs, 'mkdir');
```

断言：

```ts
expect(fs.writeFile).not.toHaveBeenCalled();
expect(fs.mkdir).not.toHaveBeenCalled();
```

---

## 6.1.4 所有错误必须断言 Error Code

禁止只断言 message。

正确：

```ts
expect(error.code).toBe('ASSET_TAMPERED');
```

错误：

```ts
expect(error.message).toContain('失败');
```

---

## 6.1.5 所有上报测试必须验证隐私字段

运行事件、History、Incident、Project State 上报必须断言：

```json
{
  "sourceCodeIncluded": false,
  "rawPromptIncluded": false,
  "rawResponseIncluded": false,
  "absolutePathIncluded": false,
  "userNameIncluded": false
}
```

```md
- [ ] Agent Profile 推荐 executor 不能覆盖 CLI 显式 executor。
- [ ] policy.json 缺失时使用默认配置，并输出 warning。

- [ ] privacyPolicy.uploadSourceCode 被配置为 true 时强制改为 false 或直接阻断。

- [ ] tokenBudget 缺失时使用默认预算。
```

## 示例测试骨架

```ts
import { describe, expect, it, vi } from 'vitest';
import { ConfigLoader } from '../../../src/config/config-loader';

describe('ConfigLoader', () => {
  it('CLI executor 应覆盖 policy 默认 executor', async () => {
    const loader = new ConfigLoader();

    const config = await loader.load({
      rootDir: '/tmp/project',
      cliOptions: {
        executor: 'codex'
      },
      runConfig: {},
      agentProfile: {
        defaultExecutor: 'claude-code'
      }
    });

    expect(config.execution.executor).toBe('codex');
  });

  it('dirtyStrategy 缺失时默认 block', async () => {
    const loader = new ConfigLoader();

    const config = await loader.load({
      rootDir: '/tmp/project',
      cliOptions: {}
    });

    expect(config.branchPolicy.dirtyStrategy).toBe('block');
  });

  it('禁止开启源码上传', async () => {
    const loader = new ConfigLoader();

    const config = await loader.load({
      rootDir: '/tmp/project',
      cliOptions: {},
      runConfig: {
        privacyPolicy: {
          uploadSourceCode: true
        }
      }
    });

    expect(config.privacyPolicy.uploadSourceCode).toBe(false);
  });
});
```


## 示例测试骨架

```ts
import { describe, expect, it, vi } from 'vitest';
import fs from 'fs/promises';
import { TechScannerEngine } from '../../../src/scanner/engine';

describe('TechScannerEngine', () => {
  it('应识别 Next.js App Router 项目', async () => {
    const engine = new TechScannerEngine();

    const result = await engine.scanWorkspace({
      rootDir: 'tests/fixtures/nextjs-app-router',
      explain: true
    });

    expect(result.packages[0].primary?.frameworks).toContain('Next.js');
    expect(result.packages[0].primary?.confidence).toBeGreaterThanOrEqual(80);
    expect(result.packages[0].reasons.length).toBeGreaterThan(0);
  });

  it('扫描阶段不得写文件', async () => {
    const writeSpy = vi.spyOn(fs, 'writeFile');

    const engine = new TechScannerEngine();

    await engine.scanWorkspace({
      rootDir: 'tests/fixtures/react-vite'
    });

    expect(writeSpy).not.toHaveBeenCalled();
  });

  it('pnpm workspace 子包应继承 root TypeScript 依赖', async () => {
    const engine = new TechScannerEngine();

    const result = await engine.scanWorkspace({
      rootDir: 'tests/fixtures/monorepo-pnpm'
    });

    const web = result.packages.find((item) => item.path === 'apps/web');

    expect(web?.primary?.language).toContain('TypeScript');
    expect(web?.reasons.join('\n')).toContain('workspace-root');
  });
});
```
