> 本章节是整个项目的最终验收标准。
> 所有勾选项必须可被测试、可被代码验证、可被文档追踪。
> 任何核心项未完成，不允许宣称 V1 交付完成。
>
> 本章节按以下维度验收：
>
> 1. `br-ai-spec` 本地执行引擎。
> 2. `skill-q-platform` 资产 Hub。
> 3. `br-ai-spec-visual` 运行态可视化平台。
> 4. Codex / Cursor / Claude Code 执行器适配。
> 5. 安全、隐私、性能、容错。
> 6. 最终发布与交付文档。

# 7.1 V1 总体验收目标

V1 版本必须完成以下闭环：

```text
扫描项目
↓
识别技术栈
↓
推荐 Manifest
↓
初始化轻量资产索引
↓
从 Hub 同步资产到本地缓存
↓
生成 Project Overlay
↓
注入 Codex / Cursor / Claude Code 指针文件
↓
/spec-start 创建需求
↓
自动创建 branch / worktree
↓
构建渐进式上下文
↓
选择执行器
↓
执行需求
↓
记录 run / history / incident
↓
上传结构化运行数据到 Visual
↓
Hub 接收资产使用反馈
```

V1 不要求完成完整远程自动开发闭环，但必须为远程任务调度、OpenClaw、钉钉机器人、Coze Provider 留好接口边界。
