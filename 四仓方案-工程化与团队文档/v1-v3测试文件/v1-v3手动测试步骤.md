# AI 工程操作系统 V1-V3 手动测试步骤

本文用于手动验证三个项目的协同闭环：

- `skill-q-platform`：Hub(资产中心)，负责资产、Manifest(方案包清单)、安装记录、运行效果分析。
- `br-ai-spec`：CLI(命令行工具)，负责从 Hub(资产中心) 安装 Manifest(方案包清单)、生成 `hub-lock.json`、上报 Runtime Event(运行事件)。
- `br-ai-spec-visual`：Visual(可视化控制台)，负责展示项目资产画像、运行洞察和治理状态。

## 0. 测试范围

### V1 要验证什么

V1(第一阶段) 验证“Hub(资产中心) 能提供方案包，CLI(命令行工具) 能安装到业务项目”。

验收点：

- Hub(资产中心) 能创建 Asset(资产) 和 Manifest(方案包清单)。
- Manifest(方案包清单) 能发布并通过 Export API(导出接口) 获取。
- CLI(命令行工具) 能执行 `hub search`、`hub install`、`hub diff`、`hub sync`。
- 业务项目生成 `.agents/registry/hub-lock.json`。

### V2 要验证什么

V2(第二阶段) 验证“安装前后可治理、可升级、可回滚”。

验收点：

- Hub(资产中心) 能提供安装前 preview(预览)。
- CLI(命令行工具) 能识别本地修改、缺失资产、过期资产。
- CLI(命令行工具) 能执行 upgrade(升级) 和 rollback(回滚)。
- Visual(可视化控制台) 能展示项目当前 Manifest(方案包清单)、资产版本、本地改动和高风险资产。

### V3 要验证什么

V3(第三阶段) 验证“运行效果能回流，Hub(资产中心) 能做分析，Visual(可视化控制台) 能看运行洞察”。

验收点：

- CLI(命令行工具) 能执行 `hub runtime-report` 上报运行结果。
- Hub(资产中心) 能在 analytics(分析) API(接口) 中展示成功率、失败原因、推荐等级。
- Hub(资产中心) 的 `/manifests/analytics` 页面能展示运行分析。
- Visual(可视化控制台) 的 `/w/[slug]/runtime-insights` 页面能展示运行洞察。

## 11. 常见问题排查

### Hub(资产中心) API(接口) 没数据

检查：

```bash
echo "$HUB_ORIGIN"
curl -sS "$HUB_ORIGIN/api/hub/search?q=react&kind=manifest" | python3 -m json.tool
```

如果返回空：

- 确认 Asset(资产) 创建是否成功。
- 确认 Manifest(方案包清单) 是否发布。
- 确认数据库连接是否是你当前启动服务使用的数据库。

### CLI(命令行工具) 安装失败，提示 checksum(校验和) 错误

说明 content(内容) 和 checksum(校验和) 不一致。

处理：

- 重新按第 5.1 步创建资产。
- 确保 `CHECKSUM_*` 是由同一份 `CONTENT_*` 计算出来的。

### CLI(命令行工具) 提示本地冲突

说明目标文件被人工改过。

处理：

```bash
node /Users/lizhenwei/workspace/vueworkspace/bairong/br-ai-spec/bin/cli.js hub diff "$TEST_PROJECT" --hub "$HUB_ORIGIN" --json
```

确认无误后再强制覆盖：

```bash
node /Users/lizhenwei/workspace/vueworkspace/bairong/br-ai-spec/bin/cli.js hub install react-standard-manual "$TEST_PROJECT" --hub "$HUB_ORIGIN" --force --json
```

### Visual(可视化控制台) 页面没有变化

优先检查：

- 当前访问的 workspace slug(工作区标识) 是否正确。
- workspace rootPath(工作区根路径) 是否指向 `$TEST_PROJECT`。
- `$TEST_PROJECT/.agents/registry/hub-lock.json` 是否存在。
- 刷新 `/w/<workspace-slug>/assets` 和 `/w/<workspace-slug>/runtime-insights`。

### Visual(可视化控制台) 和 Hub(资产中心) 端口冲突

建议：

- Hub(资产中心)：`http://localhost:3000`
- Visual(可视化控制台)：`http://localhost:18780`

启动 Visual(可视化控制台) 时明确指定：

```bash
PORT=18780 pnpm dev
```
