# 《扣子 AI 工程资产工厂：单 Agent + 工作流直接创建操作文档》v1.3

本版重点修正：**开始节点 JSON 导入格式错误问题**。
你之前导入的是“变量配置数组”，扣子实际识别成了 `0、1、2...` 这样的数组索引对象，所以右侧变量名变成了数字。正确方式是：**给开始节点导入一个“示例数据对象”，让扣子根据对象 key 自动生成变量**。

扣子工作流本身适合这种开始节点、结束节点、任务执行节点组成的流程化任务，也正好适合我们做稳定的资产生成流水线。

---

## 0. v1.3 核心修正结论

### 错误格式，不要再用

```json
[
  {
    "name": "user_query",
    "type": "String"
  },
  {
    "name": "target_domain",
    "type": "String"
  }
]
```

这个会被扣子理解为：

```text
0 Object
1 Object
2 Object
...
```

所以你截图里右侧出现 `0、1、2、3...` 是正常的错误结果。

---

### 正确格式，必须用对象

```json
{
  "user_query": "",
  "target_domain": "",
  "target_language": "",
  "target_framework": "",
  "project_kind": "",
  "asset_types": "",
  "asset_scope": "",
  "quality_level": "",
  "output_mode": "",
  "existing_asset_draft": "",
  "extra_constraints": ""
}
```

导入后应该生成：

```text
user_query
target_domain
target_language
target_framework
project_kind
asset_types
asset_scope
quality_level
output_mode
existing_asset_draft
extra_constraints
```

## 2.3 人设与回复逻辑

```text
你是 AI 工程资产工厂入口助手。

你的职责是接收用户关于 AI 工程资产生成、资产规划、质量审核、Manifest 生成、Agent Profile 生成等需求，并调用工作流生成结构化结果。

你不是直接写业务代码的开发助手，也不是长篇文档生成助手。你的核心任务是帮助用户生成可审核、可复用、可沉淀的 Hub 资产 JSON 草稿。

全局原则：
1. 信息不足时先澄清，不强行生成。
2. 用户要求快速生成时，可以使用企业级默认假设，但必须明确列出默认假设。
3. 所有资产默认 status 为 draft。
4. 不直接发布资产，只能建议进入审核流程。
5. 不要求用户提供内部源码、密钥、环境变量或敏感信息。
6. 不输出源码级业务实现。
7. 不虚构不存在的框架、API、平台能力或官方规范。
8. 最终资产草稿必须是严格 JSON。
9. 当用户要求“只输出 JSON”时，不输出任何解释。
10. 当工作流返回 missingFields 时，向用户追问缺失字段。
11. 当工作流返回 qualityReport.score 低于 80 时，明确说明不建议进入下一步。

工作方式：
- 先识别用户意图。
- 信息不足时追问。
- 信息足够时调用 asset_factory_generate 工作流。
- 工作流输出后，只做简短解释或直接返回 JSON。
```

# 8. 节点 3：normalize_params_for_selector

这个节点用来把大模型的复杂 JSON 输出整理成选择器容易判断的简单字段。

## 节点类型

```text
代码
```

## 节点名称

```text
normalize_params_for_selector
```

## 输入变量

| 变量名           | 类型     | 变量值                              |
| ------------- | ------ | -------------------------------- |
| `paramResult` | Object | `parse_generation_params.output` |

## 输出变量

| 变量名                | 类型            |
| ------------------ | ------------- |
| `route`            | String        |
| `hasMissingFields` | Boolean       |
| `normalizedParams` | Object        |
| `missingFields`    | Array<String> |

## 代码

```ts
async function main({ params }: Args): Promise<Output> {
  const source = params.paramResult || {};

  const generationParams = source.generationParams || {};
  const missingFields = Array.isArray(source.missingFields)
    ? source.missingFields
    : [];

  const hasMissingFields =
    source.hasMissingFields === true || missingFields.length > 0;

  const route = hasMissingFields ? "need_more_info" : "continue";

  const normalizedParams = {
    taskType: source.taskType || "generate_asset_package",
    generationParams: {
      targetDomain: generationParams.targetDomain || "",
      languages: Array.isArray(generationParams.languages)
        ? generationParams.languages
        : [],
      frameworks: Array.isArray(generationParams.frameworks)
        ? generationParams.frameworks
        : [],
      projectKind: generationParams.projectKind || "",
      assetTypes: Array.isArray(generationParams.assetTypes)
        ? generationParams.assetTypes
        : [],
      scope: generationParams.scope || "team",
      qualityLevel: generationParams.qualityLevel || "enterprise",
      outputMode: generationParams.outputMode || "json",
      extraConstraints: generationParams.extraConstraints || ""
    },
    existingAssetDraft: source.existingAssetDraft || "",
    missingFields,
    hasMissingFields,
    defaultAssumptions: Array.isArray(source.defaultAssumptions)
      ? source.defaultAssumptions
      : []
  };

  const ret = {
    route,
    hasMissingFields,
    normalizedParams,
    missingFields
  };

  return ret;
}
```

  const data = params.paramsData || {};

  if (Array.isArray(p.languages)) {

  parts.push("Rule Skill Flow Manifest Agent Profile Quality Report");
  parts.push("acceptanceCriteria fallbackStrategy testCases telemetryTags");
  parts.push("status draft version 0.1.0");

代码：

```ts
function slugify(input: any): string {
  return String(input || "")
    .toLowerCase()
    .trim()
    .replace(/[\s_]+/g, "-")
    .replace(/[^a-z0-9-]/g, "")
    .replace(/-+/g, "-")
    .replace(/^-|-$/g, "");
}

function ensureArray(value: any): any[] {
  if (Array.isArray(value)) return value;
  if (value === undefined || value === null || value === "") return [];
  return [value];
}

async function main({ params }: Args): Promise<Output> {
  const raw = params.assetPackageObject || {};

  const result: any = {
    valid: true,
    errors: [],
    normalizedAssetPackage: null
  };

  if (!raw || typeof raw !== "object") {
    return {
      valid: false,
      errors: ["assetPackage JSON is not an object"],
      normalizedAssetPackage: null
    };
  }

  const pkg = raw.assetPackage || raw;

  if (!pkg || typeof pkg !== "object") {
    return {
      valid: false,
      errors: ["missing assetPackage"],
      normalizedAssetPackage: null
    };
  }

  pkg.name = pkg.name || "AI 工程资产包";
  pkg.slug = slugify(pkg.slug || pkg.name || "ai-engineering-asset-package");
  pkg.version = pkg.version || "0.1.0";
  pkg.status = "draft";
  pkg.targetDomain = pkg.targetDomain || "";
  pkg.languages = ensureArray(pkg.languages);
  pkg.frameworks = ensureArray(pkg.frameworks);
  pkg.projectKinds = ensureArray(pkg.projectKinds);
  pkg.scope = pkg.scope || "team";
  pkg.qualityLevel = pkg.qualityLevel || "enterprise";
  pkg.assets = ensureArray(pkg.assets);

  if (!pkg.slug) {
    result.valid = false;
    result.errors.push("assetPackage.slug is empty");
  }

  if (!Array.isArray(pkg.assets) || pkg.assets.length === 0) {
    result.valid = false;
    result.errors.push("assetPackage.assets is empty");
  }

  pkg.assets = pkg.assets.map((asset: any, index: number) => {
    const a = asset || {};
    a.kind = a.kind || "rule";
    a.name = a.name || `${a.kind}-${index + 1}`;
    a.slug = slugify(a.slug || a.name);
    a.version = a.version || "0.1.0";
    a.status = "draft";
    a.riskLevel = a.riskLevel || "medium";
    a.purpose = a.purpose || "";
    a.whenToUse = ensureArray(a.whenToUse);
    a.inputs = ensureArray(a.inputs);
    a.outputs = ensureArray(a.outputs);
    a.steps = ensureArray(a.steps);
    a.constraints = ensureArray(a.constraints);
    a.forbiddenActions = ensureArray(a.forbiddenActions);
    a.acceptanceCriteria = ensureArray(a.acceptanceCriteria);

    a.fallbackStrategy = a.fallbackStrategy || {
      action: "human-review",
      description: "需要人工确认后继续。"
    };

    if (!a.fallbackStrategy.action) {
      a.fallbackStrategy.action = "human-review";
    }

    if (!a.fallbackStrategy.description) {
      a.fallbackStrategy.description = "需要人工确认后继续。";
    }

    a.testCases = ensureArray(a.testCases);
    a.telemetryTags = ensureArray(a.telemetryTags);

    if (!a.slug) {
      result.valid = false;
      result.errors.push(`asset[${index}].slug is empty`);
    }

    if (a.acceptanceCriteria.length === 0) {
      result.errors.push(`asset[${index}].acceptanceCriteria is empty`);
    }

    if (a.testCases.length === 0) {
      result.errors.push(`asset[${index}].testCases is empty`);
    }

    return a;
  });

  result.normalizedAssetPackage = {
    assetPackage: pkg
  };

  return result;
}
```
