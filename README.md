# br-ai-spec-docs

本仓库是 **AI 工程资产操作系统** 的**配套文档与历史资料集**，与以下三个代码仓库共同构成完整方案。开发或评审实现前，应优先阅读 **「第二大阶段」** 中的指令级 PRD/蓝图与契约文档；其他子目录为各阶段的说明、联调记录与知识库片段，可按需查阅。

## 三项目职责（与实现仓库对齐）

| 项目 | 职责概要 |
| --- | --- |
| **br-ai-spec** | 本地 CLI：技术栈扫描、项目初始化、`.ai-spec` 与锁文件、全局缓存与同步、资产校验、Git 分支/Worktree 隔离、状态机与执行器适配（Codex / Cursor / Claude Code 等，非写死单一工具）。 |
| **skill-q-platform** | 资产 Hub：Manifest、资产内容、Agent Profile、安装记录、Runtime Feedback 等 API；审核发布与版本分发。 |
| **br-ai-spec-visual** | 运行态：Collector API、运行事件与历史、项目状态上报、治理与可视化（不采集目标项目源码，需满足隐私与契约）。 |

## 与最新实现的关系

- 三仓库的**最新约束、开发顺序、红线**以各仓库内 `AGENTS.md` 为准（例如：不在扫描阶段写业务项目、不绕过 `ai-spec.lock`、不修改 Hub 已发布资产正文、核心 JSON 需 schema、CLI 与提示为中文、核心模块需测试等）。
- 端到端联调与 Mock/契约测试的归纳，可参考 **br-ai-spec** 仓库内 `docs/e2e-integration-report.md` 一类报告，与本仓库中 `br-ai-spec-history-docs`、`visual-history-docs` 的联调说明互为补充：前者偏**当前自动化与命令覆盖**，后者偏**过程性与操作手册**。

## 使用建议

1. **新成员**：先通读 `第二大阶段/1`～`4`，再按角色深入 `3`、`4` 与 `知识库文档/ai-spec规范核心架构/`。  
2. **做功能/联调**：以 `第二大阶段/4` + 各仓库合约为准；Hub/Visual 老文档若与现网 API 不一致，**以各仓库内实现与合约为准**。  
3. **做验收**：对齐 `第二大阶段/6`、`7` 与项目当前里程碑。
